# ☀️ -> ⚡ Testando modelos Baseados em Árvores para predição de geração de energia solar (W/M²) em Fortaleza
- Projeto simples que aplica Aprendizado de Máquina Supervisionado para prever geração de energia solar com base um dataset gerado de uma estação de placas solares em Fortaleza - Ceará.

## 📌 Visão Geral do Projeto
- Análise de ruído e distribuições com testes estatísticos
- Feature Engineering: Transformação e Extração de informações adicionais com base nos dados já presentes nos registros
- Análise de correlação entre as features
- Treinamento dos modelos (Árvore de decisão, XGBoost e Florestas Aleatórias)
- Métricas de testes

## 🛠️ Tecnologias e Algoritmos
As seguintes ferramentas e bibliotecas foram utilizadas no desenvolvimento:

- Python 3.13
- Google Colab
- Jupyter Notebook
- Pandas & NumPy: Manipulação e tratamento dos dados.
- Scikit-Learn: Implementação de algoritmos de regressão.
- MatplotLib e Seaborn: Exibição de gráficos com dados estatisticos.
- Astral: Informações sobre o sol em relação a terra.
